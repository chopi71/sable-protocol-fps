Sable Protocol is a round-based tactical FPS in three.js: Wardens vs Jackals on an original two-site warehouse yard, with a buy economy, a plant/defuse objective, and bots that play the lanes. First to 7 rounds; accuracy counts more than speed.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser and click to play. Keys: WASD move, mouse look, click fire, R reload, B buy menu, G grenade, E defuse, Ctrl crouch, Space jump.
